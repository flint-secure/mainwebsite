# Product Guidelines: Flint

## UI/UX Principles
- **Modern Dark Theme:** Use a deep charcoal/black background (`#09090B`) as the primary canvas.
- **High-Contrast Accents:** Utilize Amber (`#F59E0B`) for primary actions and highlights to create a clear visual hierarchy.
- **Glassmorphism:** Apply `backdrop-blur` and semi-transparent backgrounds for overlays and sticky elements (e.g., Navbar).
- **Interactive Feedback:** Use Framer Motion for subtle entry animations (Reveal) and hover states (scale, color shifts).
- **Technical Aesthetic:** Incorporate terminal-inspired code blocks and monospace fonts to reinforce the "developer-first" identity.

## Visual Identity
- **Color Palette:**
  - Backgrounds: `#09090B` (Primary), `#0F0F13` (Secondary), `#18181B` (Tertiary).
  - Text: `#F4F4F5` (Primary), `#A1A1AA` (Secondary), `#7F7F89` (Tertiary).
  - Accents: `#F59E0B` (Amber), `#22C55E` (Success), `#EF4444` (Danger).
  - Borders: `#27272A` (Subtle), `#3F3F46` (Hover).
- **Typography:**
  - Sans: 'Inter', sans-serif (for general UI and readability).
  - Mono: 'JetBrains Mono', monospace (for code, technical data, and status indicators).

## Prose Style
- **Tone:** Technical yet accessible, professional, and efficiency-oriented.
- **Terminology:** Use industry-standard terms (e.g., "latency", "real-time", "API call") while keeping explanations direct.
- **Formatting:** Use structured lists and bold highlights to make information skimmable.
